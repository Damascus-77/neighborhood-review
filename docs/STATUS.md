## 后续核对问题

- Kafka 发送内容与消费者预期对象类型是否匹配，发送失败如何恢复 Redis 预扣状态？
- 消息重复投递、抢锁失败与数据库写入失败分别如何处理，库存扣减和订单保存是否在同一事务？
- 请求标识已改用 UUID。多实例时钟偏差、用户维度鉴权接入和代理 IP 信任边界仍需分析；当前用户维度实现仍返回 anonymous。
- Caffeine 刷新读取 Redis 时，旧值可能保留多久？新增或修改优惠券后，各层缓存怎样更新？
- 数据库事务提交与删除缓存的先后关系，会产生哪些并发窗口？
- 文件上传与删除的路径、权限及输入校验是否足够？

这些问题保留用于源码阅读和后续验证，不代表已经修复。来源材料与代码存在差异时，以实际代码和可复现结果为准。
