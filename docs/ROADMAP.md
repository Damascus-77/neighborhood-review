# 工程实践路线

项目以已有本地生活业务为实验载体，逐步完成有复现步骤、修改记录和验证结果的工程改造。

| 阶段 | 内容 | 验收依据 |
| --- | --- | --- |
| 当前迭代 | 定位调整与滑动窗口计数缺陷修复 | 原脚本缺陷复现、真实 Redis 回归、Java 参数回归 |
| 下单闭环 | 核对消息序列化、消费启用、数据库事务、防重和失败恢复 | Redis 与数据库状态检查、重复及失败场景验证 |
| 缓存实验 | 核对多级缓存刷新与失效，比较三种已有模式 | 相同数据与负载、冷暖缓存说明、错误率及耗时记录 |
| 展示整理 | 可演示数据、启动流程和架构图 | 新环境可按文档复现，明确课程内容与新增改造 |

未来工作不计入当前已完成功能。每个阶段完成后更新实验记录、功能现状和修改记录。
